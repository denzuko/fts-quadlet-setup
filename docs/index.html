Install

# Download and review before running (run as root)
curl -fsSL https://denzuko.github.io/fts-quadlet-setup/fts_setup.sh -o fts_setup.sh
less fts_setup.sh
sudo sh fts_setup.sh --ip 192.0.2.10
# Override pool, service account, uid
sudo sh fts_setup.sh --ip 192.0.2.10 --pool tank --user ftsvc --uid 2001

Architecture

LayerComponentDetail
ZFS storage/containers/fts mountpoint /srv/fts — compression=lz4, atime=off
ZFS storage/users/ftsvc mountpoint /var/lib/ftsvc — service account home
Identity useradd --system uid 2001, --no-create-home, ZFS dataset is home
Linger loginctl enable-linger user manager persists across sessions, starts on boot
Delegation machinectl shell ftsvc@ all user-context ops: pull, daemon-reload, enable
Quadlet dir ~ftsvc/.config/containers/systemd/ EnvironmentFile=%h/..., WantedBy=default.target
Network fts bridge 10.89.2.0/24 — inter-container DNS, isolated from host

Operations

# Status

# Live logs

# Restart after config change
machinectl shell ftsvc@ -- systemctl --user restart freetakserver-ui.service

# Image update
machinectl shell ftsvc@ -- podman auto-update
