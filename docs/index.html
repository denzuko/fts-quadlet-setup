fts-quadlet-setup

FreeTAKServer deployed as rootless Podman Quadlet units under systemd — ZFS-backed, service-account-isolated, HAProxy-fronted.

v1.0.0 rootless BSD 2-Clause POSIX sh ShellCheck clean

Install

Run as root on any systemd host with Podman ≥ 4.4 and a ZFS pool named storage.

# Download and review before running
curl -fsSL https://denzuko.github.io/fts-quadlet-setup/fts_setup.sh -o fts_setup.sh
less fts_setup.sh
sudo sh fts_setup.sh --ip 192.0.2.10
# Override pool, service account name/uid
sudo sh fts_setup.sh --ip 192.0.2.10 --pool tank --user ftsvc --uid 2001

Operations

# Status (run as root)
machinectl shell ftsvc@ -- systemctl --user status freetakserver.service

# Live logs
machinectl shell ftsvc@ -- journalctl --user -u freetakserver.service -f

# Restart after config change
machinectl shell ftsvc@ -- systemctl --user restart freetakserver-ui.service

# Manual image update
machinectl shell ftsvc@ -- podman auto-update
