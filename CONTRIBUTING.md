# Contributing

## Workflow
1. Open GitHub Issue
2. Branch: feat/N or fix/N
3. Write BATS test first
4. Write code until tests pass
5. Update CHANGELOG.md
6. Push → PR → review → merge → tag

Never commit directly to main. BDD order is mandatory.

## Semver
- MAJOR — breaking change to installer API or container interface
- MINOR — new non-breaking capability
- PATCH — everything else
